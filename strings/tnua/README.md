# TNUA violin fingering dataset (copy)

The 140 CSV files of the TNUA violin fingering dataset: 10 professional violinists (`vio1` … `vio10`) × 14 excerpts, each note annotated with string, position and finger. Columns: `pitch,start,duration,beat_type,string,position,finger`. The format is described in [../tnua.js](../tnua.js).

- Source: https://github.com/Tsung-Ping/Violin-Fingering-Generation (`TNUA_violin_fingering_dataset/`), commit `39dc7d9` (21 Apr 2025), copied unchanged.
- Paper: Cheung, Kao and Su, "Positioning Left-hand Movement in Violin Performance: A System and User Study of Fingering Pattern Generation", IUI 2021, https://doi.org/10.1145/3397481.3450661
- The source repository has no licence file. The data stay the authors'; they are copied here so the #033 page and `strings/test/tnua.js` work without a separate clone.

The pieces: Bach (Partita No. 2 Allemanda, Partita No. 3 Preludio), Mozart (Concerto K. 216, I and III), Beethoven (Sonatas Op. 24 I and Op. 30/1 III), Elgar (Salut d'Amour), Mendelssohn (Concerto, I), and Teng Yu-hsien (Bāng Chhun-hong, Ú-iā-hue).
